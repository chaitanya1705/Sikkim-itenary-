# Sikkim + Darjeeling Itinerary (7–11 Nov 2026)

An interactive, animated trip planner for a Bengaluru → Sikkim → Darjeeling trip, made by **Chaitanya N**.

## Features
- Two switchable plans: **Plan A** (East Sikkim + Nathula) and **Plan B** (North Sikkim + Pelling)
- Animated elevation skyline and live countdown to departure
- Real-border route map (Sikkim districts, Darjeeling, Teesta river) with a moving cab/plane
- Day-by-day timeline with illustrated scenes and a photo gallery per stop
- Google Maps driving route for each day
- Interactive altitude chart with high-altitude tips
- Permit guide and document checklist per plan
- Packing checklist with progress ring (saved on each device)
- Copy / WhatsApp brief for the cab operator
- Light and dark themes, phone and laptop layouts

## Run it
It's a single self-contained file. Open `index.html` in any browser.

## Host it free on GitHub Pages
Repo **Settings → Pages → Deploy from a branch → `main` / root**. The page will be live at
`https://<your-username>.github.io/sikkim-darjeeling-itinerary/`.

## Data notes
Boundaries: geohacker/india district data and Natural Earth (countries, rivers). Timings, permits and road conditions are planning estimates; reconfirm with your operator before travel.
